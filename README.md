# Career-trajectory-researcher-predictor
This project analyzes how computer science researchers’ topics and publication venues evolve over time using the DBLP publication dataset. Paper titles and abstracts are converted into TF-IDF features, then clustered into topic groups using MiniBatch K-Means. The project includes visualizations of the final analysis as well.

to run this project you must also download the dataset at https://open.aminer.cn/open/article?id=655db2202ab17a072284bc0c and the notebook must be edited to point to your data file.
